# Gilman News Project

App in development for local school newspaper. Currently has ability to interface with online database to display articles, images, and authors. Basic Search Functionality has been implemented. User Stats have been implemented and store information on local device for simplicity. Recommended authors and following of specific author currently implemented. Read/unread articles implemented. roughly 3-4 years of articles (so 430) available currently. Two Games currently available - Curling (lol) and Gilman Connections. If interested in Beta Testing, reach out here: gilmannews@gilman.edu and I will get back to you.

Most Recent Update 5/17/26: Version 1.0.1 Minor Updates with some cool changes! Tags for articles are added. Minor Changes to some content. Critical search bug patched. Many, Many Design updates, mainly centered on fixing a major issue where apple's accesibiity features for larger text size destroyed the app. Also, Push Notification!

To view the code, got to lib/pages or lib/services.

Note\* because stats are stored locally, the stats only works for emulators or iphone/android themselves.
